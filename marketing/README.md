# Financial Hub — Marketing site

Public / investor landing page for Financial Hub.

## Run locally

```bash
cd marketing
pnpm install
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
pnpm build
pnpm preview
```
